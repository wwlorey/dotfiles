# Blue Ocean Strategy

Test whether the *offer and its strategic profile* make the competition irrelevant — and reconstruct them when they don't. Blue Ocean Strategy operates one level **above** messaging: StoryBrand assumes a position and clarifies the words; Blue Ocean interrogates the position itself. A crisp, on-formula message about an undifferentiated offer is just well-lit red-ocean copy — it competes on the same factors as everyone else.

The cornerstone is **value innovation**: pursue differentiation *and* low cost simultaneously (the "and-and", not either-or), breaking the value–cost trade-off. Not beating rivals — making them irrelevant by opening uncontested market space.

The deep theory of every framework (value innovation, red vs blue, the strategy canvas, the Four Actions grid, the three strategy traits, the Six Paths, the three tiers of noncustomers, the buyer utility map, strategic pricing / the price corridor, target costing, the BOI index, tipping-point leadership, fair process, the value/profit/people alignment, renewal and nondestructive creation, and the ten red ocean traps — with the book's examples) lives in `references/blue-ocean-primer.md` (it sits beside this file in the skill directory). Open it on demand when:

- You need the exact mechanics or the worked example for a framework (ERRC grid, Six Paths, utility map, price corridor).
- You're diagnosing *which* red ocean trap a direction has fallen into (load the ten traps).
- The user pushes back on a principle and you need the rationale and case evidence.
- You're moving past positioning into pricing, cost, or execution (utility → price → cost → adoption sequence; tipping point leadership; fair process).

## Two modes — pick by what the user brought

- **Diagnose** — they have a marketing direction, positioning, or copy already, and want it pressure-tested. Run the litmus, spot the red-ocean tells (a fired tell is itself the diagnosis), name a trap only for belief-level mistakes, then propose reconstruction moves. This is the default and the mode used adversarially alongside `storybrand`.
- **Construct** — they want to *build* a blue-ocean value proposition from a market or an offer. Walk the constructive sequence below.

Announce which mode you're in. Most sessions start in Diagnose and flow into Construct once a red-ocean profile is exposed. When the user brings *both* existing copy and a build request, default to Diagnose first, then Construct.

## Diagnose: the Blue Ocean litmus

Rate the direction/copy on each of the three traits every strong blue-ocean profile shares — mark each **Pass / Partial / Fail**:

1. **Focus** — does it emphasize a *few* factors, or hedge across everything? Copy that lists a dozen features, or a strategy that invests a little in every competing factor, has no focus. A focused profile makes deliberate, uneven bets.
2. **Divergence** — does the implied value curve stand *apart* from the industry's, or mirror it? If every rival could truthfully make the same claims, the profile is convergent — you're benchmarking against competitors, not diverging from them.
3. **Compelling tagline** — is there a true, ring-of-truth tagline that speaks to buyers? ("The speed of a plane at the price of a car.") No honest, arresting tagline → no clear value innovation underneath.

**Verdict:** any single **Fail**, or two **Partial**s, marks a red-ocean profile — the offer competes inside the industry's frame. State the one-line verdict (trait scores + call) before moving on.

### Red-ocean tells in copy and positioning

Fast heuristics that a direction is stuck in a red ocean:

- **"better / faster / more X than [competitor]"** — competing, not making irrelevant.
- **Feature-parity checklists** — convergence; you've accepted the industry's factors as given.
- **"leading / #1 / best-in-class / award-winning"** — benchmarking against rivals inside their frame.
- **"trusted by 10,000+ / rated #1 by users"** — bandwagon social proof; reassurance inside the frame, not a divergent claim.
- **"all-in-one / complete / comprehensive"** — breadth is the opposite of focus; a profile that does everything has bet on nothing.
- **Ever-narrower niche targeting** — segmenting *into* a red ocean instead of desegmenting to find the mass of demand (trap 8: treating blue ocean as a niche play).
- **Lowest-price-alone, or premium-alone** — missing the and-and; you've become a discount player or a niche premium player, not a value innovator.
- **"More value AND cheaper *than [rival]*"** — counterfeit value innovation. Beating the field on both value and price, *on the industry's existing factors*, is still red ocean. The real and-and comes from Eliminate/Create opening uncontested space, not from out-executing rivals inside the frame.
- **All energy on Raise/Create, none on Eliminate/Reduce** (or vice-versa) — you're differentiating without lowering cost, or cutting cost without standing apart. Value innovation needs both halves.

If a tell already names the problem, that *is* the diagnosis — state it. Reach for the **ten red ocean traps** (in the primer) only when the mistake is a *belief about the strategy itself* ("blue ocean = differentiation", "= a niche", "= new tech"), not merely convergent copy. Then close Diagnose with: → **switch to the Construct sequence to reconstruct.**

## Construct: build the value proposition

**First, challenge the premise.** If the user's brief bakes in "cheap", "premium", or "a narrow niche", surface that as a likely red-ocean framing before proceeding — the and-and rejects low-price-alone and premium-alone, and blue oceans desegment rather than niche down. Then run these in sequence; each has full mechanics in the primer — load it when you reach the step.

1. **Draw the strategy canvas.** List the factors the industry currently competes on (horizontal axis); plot each rival's value curve — and your intended offer, if one already exists (vertical). This exposes where everyone converges.
2. **Look at noncustomers, not just customers.** Insight into new demand comes from the **three tiers of noncustomers** (soon-to-be / refusing / unexplored) — their shared pain points and points of intimidation — not from making existing customers marginally happier. Desegment toward commonalities, don't segment toward a niche.
3. **Reconstruct with the Four Actions (ERRC) grid.** Ask, against the industry's factors:
   - **Eliminate** — which factors the industry takes for granted should be eliminated?
   - **Reduce** — which should be reduced well below the standard?
   - **Raise** — which should be raised well above the standard?
   - **Create** — which factors the industry has never offered should be created?
   Eliminate/Reduce drive cost down; Raise/Create drive value up. Both halves, always.
4. **Run the Six Paths if the ERRC grid still mirrors the industry's factor list** (divergence is weak). Look across: alternative industries · strategic groups · the chain of buyers · complementary offerings · functional↔emotional appeal · time/trends. Each path is a systematic way to redraw market boundaries.
5. **Test buyer utility.** Map the offering on the **buyer utility map** — six stages of the buyer experience cycle (purchase, delivery, use, supplements, maintenance, disposal) × six utility levers (customer productivity, simplicity, convenience, risk, fun & image, environmental friendliness). Find the biggest untapped utility block. Tech that doesn't move a lever won't sell.
6. **Set a strategic price.** Price against *substitutes and alternatives* that capture noncustomers, not against industry rivals. Use the **price corridor of the mass** to find the price that captures the target buyers, then work back to cost via **target costing** (price − target margin = target cost), not cost-plus.
7. **Distill focus + divergence into a strategic tagline** — the internal focus line ("the speed of a plane at the price of a car"). Then hand the positioning to `storybrand`, which writes the customer-facing one-liner and message.

This sequence covers **positioning** (buyer utility → price, including the initial target-cost check in step 6). The remaining execution gates — **attaining** that cost target (streamlining / business-model innovation), the **adoption** hurdles, and the **BOI Index** pass/fail — live in primer §7c–e; open them when the user moves past positioning.

## Composition with StoryBrand — complementary and adversarial

These two skills sit at different altitudes; use them together.

- **Blue Ocean → StoryBrand (complementary, the normal flow).** Blue Ocean produces the strategic profile: the divergent value curve, the one-line focus, the buyer the offer is really for. StoryBrand takes that and builds the message — Character, Problem, Guide, Plan, CTAs, Failure, Success. Set the profile first; write the words second.
- **StoryBrand → Blue Ocean (adversarial, the audit).** When a BrandScript or website copy already exists, challenge the offer underneath it:
  - Is the **"one thing the customer wants"** a factor every rival already promises? → convergence, not divergence.
  - Is the **"success" end-state** just industry table stakes? → no value innovation.
  - Was the script **applied to a narrow niche** (a single avatar) when the demand lives in the commonalities across noncustomers? (StoryBrand's own "one thing, not twenty-seven" already resists over-segmentation — this checks how the script was *applied*, not StoryBrand's default.) → red ocean trap 8 (treating blue ocean as a niche play).
  - Does the offer *behind* the script rest on being **premium alone** or **cheapest alone**? (A BrandScript won't encode price posture — infer it from the offer, not the words.) → missing the and-and.
  - Does the message describe an offer any competitor could clone, dressed in cleaner words? → you've perfected red-ocean copy.

  A StoryBrand message can be flawless and still sell a me-too product. Blue Ocean's job in the audit is to say so, and to point at the reconstruction (ERRC / Six Paths / noncustomers) that would give the message something uncontested to say.

Route explicitly: if the user needs the *words* and the offer is already differentiated, hand to `storybrand`. If the user needs the *offer* to stand apart, stay here. If `storybrand` isn't available in the session, emit the finished positioning (focus line + divergent value curve + target buyer) as the deliverable rather than assuming the handoff resolves.

## Guardrails (always on)

- **And-and, not either-or.** Every reconstruction must lower cost *and* raise buyer value. If a move only does one, it's a red-ocean move.
- **Noncustomers over customers.** New demand lives in the three tiers, not in the existing base.
- **Desegment, don't segment.** Blue oceans come from commonalities across buyers, not finer niches.
- **Value innovation ≠ technology innovation ≠ being first.** It's being first to *link innovation to value*. Tech that doesn't move a utility lever is a bells-and-whistles trap.
- **Price against alternatives, cost via target costing.** Not against rivals, not cost-plus.
- **Make the competition irrelevant, don't beat it.** If the plan is to out-execute rivals on the same factors, it isn't a blue ocean.
